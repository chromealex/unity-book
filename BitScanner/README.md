# BitScanner

Код к главе 5, раздел про перебор битовой маски через `tzcnt`.

`BitScanner.GetTrueBits` пишет индексы всех установленных битов маски. Вместо проверки каждого из 64 бит слово
обрабатывается через `math.tzcnt`: цикл делает столько шагов, сколько в слове единиц. Пустые слова пропускаются,
полностью заполненные пишутся одним проходом. Последнее неполное слово маскируется, мусор за пределами длины не попадает в результат.

- `BitScanner` — скалярная версия: `GetTrueBits`, `GetTrueBitsCount`, `WriteTrueBits` (постранично: пропустить N установленных битов и взять следующие M).
- `BitScannerSimd` — варианты на интринсиках AVX2, SSE2 и NEON. SIMD сортирует слова (пустые, полные, остальные) по 2–4 за инструкцию. Интринсики работают только в коде, скомпилированном Burst, в обычном C# вызов уходит в скалярную версию.

Зависимости: Burst, Collections, Mathematics. Тесты (EditMode) сравнивают обе версии с наивным перебором битов на масках разной плотности и длины; SIMD-версия проверяется внутри Burst-джобы.

```csharp
var bits = BitScanner.GetTrueBits(maskPtr, bitLength, Allocator.Temp);
for (int i = 0; i < bits.Length; ++i) {
    var index = bits[i];
    // ...
}
bits.Dispose();
```
